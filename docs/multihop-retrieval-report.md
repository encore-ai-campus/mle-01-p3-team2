# GraphRAG Multi-hop 검색 초기 이슈 및 최종 개선 결과

## 1. 작업 개요

식물 재배 GraphRAG 프로젝트의 **GRAPH / HYBRID 기반 Multi-hop 검색**에서 초기 평가 성능이 매우 낮게 나타나 원인을 분석하고 검색 경로 생성, 랭킹, 라우팅 및 병합 로직을 개선했다.

- **작업 범위:** GRAPH 검색, Multi-hop 경로 탐색, 질문 라우팅, HYBRID 검색 병합 및 성능 평가
- **평가 원칙:** 평가 문항·정답셋·exact-match 채점 기준을 유지하고, Gold ID는 검색 입력이나 점수 계산에 사용하지 않음
- **최종 상태:** 추가 검색기 변경은 중단하고, 개선된 기본 설정(후보 수 30)을 유지

## 2. 초기 평가에서 발견된 이슈

### 2.1 초기 성능

| 평가 지표 | 초기 결과 |
|---|---:|
| 전체 라우팅 정확도 | 24/67 (35.82%) |
| VECTOR Hit@10 | 15/19 (78.95%) |
| GRAPH Hit@10 | 1/21 (4.76%) |
| HYBRID Hit@10 | 3/17 (17.65%) |
| Multi-hop 완전 성공 (라우팅 포함) | 0/17 (0%) |
| Multi-hop 필수 노드 경로 일치 | 1/17 |
| Multi-hop 필수 관계 ID 일치 | 1/17 |
| 관계 유형 충족 / 최소 hop 충족 | 각각 3/17 |
| 관계 원문 연결 / 정답 근거 일치 | 각각 1/17 |

### 2.2 주요 이슈

1. **질문 라우팅 오류:** 전체 67문항 중 43문항에서 기대 검색 경로와 실제 라우팅이 불일치. Multi-hop 17문항 중 라우터 일치는 3문항뿐이었음.
2. **GRAPH 정답 경로 미회수:** 라우터를 우회해 강제 GRAPH 검색을 실행해도 GRAPH Hit@10은 1/21이었고, Multi-hop 경로 성공은 1/17에 그침. Multi-hop 16문항에서 필수 노드·관계 ID를 포함한 경로가 검색되지 않았음.
3. **부적절한 후보 제한과 정렬:** 경로 길이와 내부 노드 ID 중심의 사전 정렬·제한으로 질문과 관련된 2-hop 경로가 후보 단계에서 누락될 수 있었음.
4. **HYBRID 병합 중 경로 순위 하락:** GRAPH에서 회수된 경로가 VECTOR 결과와 병합된 뒤 Top-10 밖으로 밀리는 사례 발생.
5. **동형 경로 간 순위 경쟁:** 동일 작물·병해충에 연결된 농약 제품 경로가 다수 존재하여, 질문에 제품 식별 단서가 없는 경우 단일 Gold 경로를 우선하기 어려움.

**데이터 무결성 확인:** 초기 진단에서 Neo4j의 entity 58/58, relation 55/55, evidence 58/58, chunk 59/59가 존재했고, 확인한 55개 관계의 endpoint/type/evidence/chunk 매핑도 일치했다. 따라서 주된 문제는 데이터 ID 누락보다 검색 및 평가 구조에 있었음.

## 3. 단계별 개선 작업

### 3.1 GRAPH 후보 탐색 및 엔티티 앵커링 개선

- 질문에 등장하는 작물명·관계 표현을 활용하여 시작 엔티티 매칭 및 후보 경로 생성을 개선.
- 단일 앵커를 찾지 못하는 질문에 fallback 탐색 적용.
- 초기의 경로 길이·내부 ID 중심 사전 제한을 점검하고 경로 관련성 기반 후보 선정 강화.
- 기본 후보 수를 **30개**로 설정(정확도와 검색 시간 절충).

**성과:** 후보 30 기준 GRAPH Hit@10 **1/21 → 8/21**, Multi-hop GRAPH 경로 성공@10 **1/17 → 7/17**. 작물 앵커 명시 매칭은 **37/38**, 후보 경로 생성은 **38/38**.

### 3.2 GRAPH 경로 랭킹 개선

- 질문 엔티티, 관계 의도 및 순서, 경로 연결성, 원문 연결, 요청된 사용 조건 등을 반영하여 재랭킹.
- 경로 길이 자체에 대한 가산점은 제거하고 동점일 때 기존 후보 순서를 유지.
- 동일한 후보 집합을 기준으로 기존/개선 랭킹 비교 및 회귀 검사.

**성과:** 기본 후보 30에서 GRAPH Hit@10 **8/21 → 9/21**. Multi-hop GRAPH 경로 성공@10은 **7/17 유지**, 기존 성공 문항 퇴행 없음. GS061의 정답 경로는 앞선 탐색 개선 과정에서 **5위 → 1위**로 향상되었으며, 재랭킹 비교 시에도 1위를 유지.

### 3.3 QuestionRouter 분류 규칙 개선

- 관계 조회, 설명·근거 필요성, 세부 조건의 조합을 바탕으로 `VECTOR / GRAPH / HYBRID / REJECT` 분류 규칙 재구성.
- 문항 ID 및 Gold 경로를 분류 규칙에 사용하지 않음.

**성과:** 전체 라우팅 정확도 **24/67 → 62/67 (92.54%)**, Multi-hop 라우팅 일치 **3/17 → 17/17 (100%)**. 강제 GRAPH/VECTOR 검색 성능은 유지.

### 3.4 HYBRID 병합 및 경로 보존 개선

- GRAPH와 VECTOR 결과를 병합할 때 GRAPH 관계 경로가 사라지지 않도록 처리.
- 동일 evidence/chunk가 겹치는 경우에도 GRAPH 경로를 유지하고 VECTOR 원문은 `matched_vector_hits`에 연결.
- RRF 가중치(기존 1.0/1.0 → 개선 1.1/1.0)와 질문 어휘·경로 노드·관계 표현 일치도를 활용해 순위 개선.

**성과(동일 후보 집합 비교):** HYBRID Hit@10 **6/17 → 9/17**, Multi-hop 완전 성공@10 **6/17 → 9/17**, GRAPH 정답 경로 보존 **6/10 → 9/10**, VECTOR 정답 손실 **0건**. 전체 회귀 테스트 **93개 통과**.

> 단계별 수치 중 HYBRID의 6/17은 동일 후보 집합에서 수행한 병합 전후 비교의 **기준값**이며, 최초 전체 평가의 HYBRID 3/17과는 측정 시점·조건이 다르다.

### 3.5 미회수 경로 진단 및 회귀 방지

- 실패 7문항의 Gold 경로가 Neo4j에 정방향 2-hop으로 존재하고, 원문 근거도 연결되어 있음을 확인.
- 제품별 유사 경로 **79~257개**로 인해 사전 후보 컷오프와 순위 경쟁이 발생함을 확인.
- 후보 수 30/50/100 비교 시 완전 경로 후보 회수는 **10/17 → 12/17 → 16/17**로 증가했으나, GRAPH Top-10 완전 성공은 **7/17 → 6/17 → 4/17**로 감소.
- 후보 확장 실험에서 통합 HYBRID 성공이 **9/17 → 7/17**로 퇴행해 해당 변경을 **반영하지 않고 롤백**.

### 3.6 정답 경로의 구별 가능성 진단

- 17문항 중 질문 자체에서 특정 Gold 경로를 구별할 수 있는 문항은 **2/17 (GS011, GS061)**.
- **15/17**문항에서는 서로 다른 제품 노드를 거치는 대체 경로가 존재.
- HYBRID Top-10에 구조적으로 유사한 대체 경로가 있는지 확인한 보조 지표는 **17/17**이었음.
- 단, 이 지표는 **Gold exact-match 성공률이 아니며**, 대체 농약 제품의 실제 사용 적합성·공식 등록 여부도 입증하지 않음.
- 평가셋과 채점 기준은 변경하지 않고 분석 결과만 기록함.

## 5. 남은 이슈 및 한계

| 유형 | 관련 문항 | 상태 |
|---|---|---|
| GRAPH 후보 회수·순위 경쟁 | GS012, GS018, GS026, GS027, GS036, GS067 | 대량의 유사 경로와 후보 제한으로 Gold 미회수 또는 저순위 |
| HYBRID 병합 후 순위 하락 | GS054 | GRAPH Top-10의 Gold가 HYBRID Top-10에서 누락 |
| 후보 수에 따른 순위 불안정 | GS066 | 후보 30/50에 따라 Gold 순위 변화 |
| 정답 경로의 비유일성 | 15/17문항 | 제품 식별 정보가 부족하여 복수의 구조적 대체 경로 존재 |

- 평가셋은 추가 개선하지 않았고, **기존 exact-match 기준 9/17**을 최종 공식 성능으로 유지.
- **구조적 대체 경로 17/17**은 보조 진단 결과일 뿐 실제 정답률로 제시하지 않음.
- 특정 농약의 적합성이나 등록 상태는 별도 공식 근거 검증이 필요함.

## 6. 최종 결론

초기 Multi-hop 검사에서는 라우팅 오류, GRAPH 정답 경로 미회수, 후보 컷오프, HYBRID 병합 순위 하락이 중첩되어 **완전 성공 0/17**을 기록했다. 엔티티 앵커링·경로 탐색·랭킹·라우팅·병합을 단계적으로 개선한 결과 **최종 통합 Multi-hop 9/17(52.94%)**, 전체 라우팅 정확도 **62/67(92.54%)**를 달성했다.

남은 실패 사례는 대량의 유사 제품 경로 및 질문에 부족한 제품 식별 정보와 관련이 깊다. 성능 퇴행을 초래하는 후보 수 확대는 채택하지 않았으며, **기본 후보 수 30과 기존 평가 기준을 유지한 채 Multi-hop 최적화 작업을 종료**했다.
